# Non-Negotiable Rules

1. **Real over simulated.** Demo mode may exist, but REAL mode is physically separate and never conflated with it.
2. **Claim != Evidence.** No Stage Clear without actual evidence.
3. **Runtime truth drives 3D.** Animation cannot create authoritative work state.
4. **Persistent K-Agent != model.** A model/provider is cognition infrastructure, not Agent identity.
5. **Provider-independent cognition.** Ollama is optional. Endpoints/model names are configurable and swappable.
6. **Autonomous by default.** Manual assignment is an override.
7. **1–5 member parties.** Party size follows mission complexity, not a fixed 3-agent rule.
8. **★1–★7, not E/D/C/B/A/S.** Star rank is evidence-based developmental/work maturity, not generic power.
9. **Star != skill != career.** A ★3 specialist can outperform a ★5 generalist on a specific task.
10. **No hard locks.** World level describes emerged structure; it does not arbitrarily forbid capability.
11. **Organic expansion.** World/buildings grow because real use/demand makes new form necessary.
12. **Failure != Agent fault.** Attribute environment, mission-design, authority and Agent-caused failure separately.
13. **Synthesis is serious.** Worker identity/memory/personality/skills/relationships/self-model can be deleted when policy criteria are met; anonymized reusable World Lesson may remain.
14. **No resurrection of synthesized Agent identity.** New Agent may learn public World Lessons but cannot inherit the destroyed personal continuity.
15. **Mother is separate.** KRAUDE Mother is not worker, not starred, not synthesized, not scheduled by the worker assignment engine.
16. **Mother's neural identity is independent.** External foundation-model weights are never transplanted as Mother identity.
17. **Real Git isolation.** Real missions use worktrees/reversible boundaries and record diffs/HEADs.
18. **Authority boundaries are explicit.** Consequential external actions require permission.
19. **World survives UI closure.** The real runtime runs outside the React render loop/browser tab.
20. **Crash recovery is part of functionality.** Durable queue/event/state must survive restart.
21. **Pick Me Up is a structural/visual reference, not the ontology of KRAUDE.** Use the user's research as source truth for reference facts; label adaptations clearly.
22. **Do not call mock completeness 100%.** Strict audit gates decide completion.
